# 成长日记微信小程序原型

这是“成长日记”的第一阶段纯前端原型，使用微信原生 TypeScript 开发。当前版本不需要腾讯云资源，不连接真实服务器，也不具备云端备份能力。

## 已实现

- 温暖成长相册风格与四栏底部导航。
- 进入时先选择家庭，再选择该家庭下的宝宝；家庭之间的数据完全隔离。
- 多宝宝档案、成长墙、照片/视频本地预览。
- 普通日记、自定义里程碑、身高/体重/头围记录。
- `OWNER`、`ADMIN`、`MEMBER` 三种演示身份切换。
- 成员只能编辑自己的记录，管理员可以永久删除任意记录。
- 可创建家庭、使用一次性邀请码加入家庭，并调整或移除成员。
- 家庭数据按成员关系隔离；非成员不能读取该家庭的宝宝、记录与本地素材引用。
- 首页提供独立的系统管理员入口，可查看全局统计并维护所有家庭的成员权限；系统管理页不展示宝宝媒体。
- 按宝宝和月份创建模拟导出、模拟下载及人工备份确认。
- 所有页面只调用服务接口，Mock 数据与页面实现解耦。

## 启动方式

1. 安装依赖：`npm install`
2. 检查 TypeScript：`npm run typecheck`
3. 使用微信开发者工具导入项目根目录。
4. 当前 `appid` 为 `touristappid`，可直接使用测试号/游客模式预览；准备好真实 AppID 后在微信开发者工具中替换。
5. 真机预览前建议清理一次缓存，确保从初始演示数据开始。

## HTML 交互原型

不安装微信开发者工具也可以查看 `prototype/index.html`。直接双击打开即可；如浏览器限制本地脚本，可在项目根目录运行 `npm run prototype`，再访问终端显示的本地地址。

## 原型数据说明

Mock 数据保存在小程序 Storage 中，存储键为 `growth_diary_prototype_state_v3`。旧的第 3 版数据会自动补充系统管理员字段，不会因本次升级被清空。选择本机照片或视频时会尝试使用小程序本地文件沙箱保存；受小程序本地配额限制，大文件可能只在当前会话有效。

原型权限规则：家庭创建者可调整或移除非创建者成员；管理员可邀请成员，并可移除普通成员；普通成员可查看当前家庭和发布自己的记录。上述限制仅用于本地原型验收，正式版仍需由后端 API 和私有 COS 鉴权执行，不能把前端判断当作真实安全边界。

系统管理员与家庭角色相互独立。原型中“妈妈”为系统管理员，可查看家庭、用户、宝宝、记录和素材数量，并维护非创建者成员；系统管理员不会因此自动获得家庭照片查看权限。

“我的”页面提供“重置演示数据”。重置会清除原型中新增的档案、记录、媒体引用和导出状态。

请勿使用当前版本长期保存真实宝宝素材。

## 接入后端时的替换点

页面统一依赖 `miniprogram/services/contracts.ts` 中的服务接口。腾讯云准备完成后：

1. 实现 `HttpServiceContainer`。
2. 在 `miniprogram/services/index.ts` 中将 `mockServices` 替换为 HTTP 实现。
3. 保持现有页面与模型类型不变。
4. 将本地素材保存替换为后端签发临时凭证后的 COS 直传。

`.env.example` 仅提供未来后端配置名称，不包含任何真实密钥。

## 已知边界

- 不会生成真实 ZIP。
- 不连接夸克网盘。
- 不接入内容安全审核。
- 不提供公开分享、评论、点赞和视频转码。
- 原型中的永久删除只作用于本机 Mock 数据。
